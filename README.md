# Sales Dashboard 2026 | Power BI

## Project Overview
This project presents an interactive sales dashboard developed using Microsoft Power BI. It helps analyze sales performance across time periods, products, product categories, and countries.

## Dashboard Preview
![Sales Dashboard 2026](screenshots/dashboard_preview.png)

## Key Performance Indicators
- **Total Orders:** 100
- **Total Customers:** 12
- **Total Sales:** 103K (as displayed in the dashboard)

## Dashboard Features
- Sales trends by year and quarter.
- Sales comparison across individual products.
- Sales distribution by product category.
- Interactive date and country filters.
- Product category filtering.

## Tools and Technologies
- Microsoft Power BI Desktop
- Power Query, if used for data preparation
- DAX, if used for measures or calculations
- Microsoft Excel or CSV for the source dataset

## Business Questions
- How do sales change over time?
- Which products contribute the most to sales?
- Which product categories account for the largest share of sales?
- How can users compare sales across countries and dates?

## Project Files
- `Sales_Dashboard_2026.pbix` — Power BI report.
- `data/` — source dataset, if safe to share.
- `screenshots/` — dashboard preview images.

## How to Use
1. Download the Power BI report file.
2. Open it using Microsoft Power BI Desktop.
3. If prompted, connect to the appropriate source dataset.
4. Refresh the report if required and explore the interactive filters.
